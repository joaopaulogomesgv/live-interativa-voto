🎬 Como adicionar no TikTok LIVE Studio / OBS Studio

  1. Abra o TikTok LIVE Studio no seu computador.
  2. Clique em Adicionar Fonte e selecione Link / Navegador (Browser Source).
  3. Cole a URL: http://localhost:3000
  4. Defina a resolução recomendada para 1080 x 1920 (ou ajuste para preencher a tela vertical).
  5. Pronto! Você pode controlar tudo por este painel enquanto transmite.
